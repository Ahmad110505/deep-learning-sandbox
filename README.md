# 🧠 Deep Learning & Neural Networks Sandbox

A structured collection of hands-on implementations, models, and deep learning experiments covering foundational neural networks, computer vision, PyTorch, Keras/TensorFlow, and Hugging Face Transformers.

---

## 📂 Repository Structure

```
.
├── Transformers/           # Hugging Face Transformers & NLP models
├── first_neural_network/   # Custom neural network from scratch
├── keras/                  # Keras / TensorFlow model architectures & training notebooks
└── pytorch/                # PyTorch neural network modules, datasets, and pipelines
```

---

## 🚀 Key Modules & Topics

### 1. **Transformers (`/Transformers`)**
- Implementations of Transformer-based models for text classification, attention mechanisms, and pre-trained model fine-tuning.

### 2. **Foundations (`/first_neural_network`)**
- Building a feedforward neural network from first principles using Python and NumPy.
- Backpropagation, activation functions (ReLU, Sigmoid, Softmax), gradient descent optimization, and loss calculations.

### 3. **Keras & TensorFlow (`/keras`)**
- High-level deep learning modeling, convolutional neural networks (CNNs), recurrent neural networks (RNNs), and training callbacks.

### 4. **PyTorch (`/pytorch`)**
- Modular PyTorch `nn.Module` classes, custom Dataset & DataLoader pipelines, GPU acceleration, and model evaluation routines.

## 🛠 Prerequisites & Installation

```bash
# Clone the repository
git clone https://github.com/Ahmad110505/neural-networks.git
cd neural-networks

# Create virtual environment
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

# Install core dependencies
pip install torch torchvision torchaudio tensorflow keras transformers numpy pandas matplotlib jupyter
```
